## ⚡ 15-Minute Quick Start

### Step 1: Create SendGrid Account (2 min)
https://sendgrid.com → Sign up

### Step 2: Get API Key (2 min)
https://app.sendgrid.com/settings/api_keys → Create API Key

### Step 3: Verify Email (5 min) ⚠️ CRITICAL!
https://app.sendgrid.com/settings/sender_authentication → Verify

### Step 4: Update Configuration (2 min)
Create/edit `Back End/server/.env`:
```
SENDGRID_API_KEY=SG.your_key_here
SENDGRID_FROM_EMAIL=noreply@yourdomain.com
SENDGRID_FROM_NAME=Lakshmi Function Hall
ADMIN_EMAIL=admin@domain.com
```

### Step 5: Restart & Test (2 min)
```
Stop server: Ctrl+C
Start server: node server.js
Test: node testSendGrid.js
```

**Total: 13-15 minutes. Done!**
